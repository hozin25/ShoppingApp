# Skill：代码库自动分析 → 完整简历项目描述（含Demo）

## 作用
自动读取我的项目代码 / GitHub 仓库 / Git 提交记录，
按**标准简历项目格式**输出完整内容，
并为我负责的模块自动生成**精简 Demo 代码**。

## 输入
1.我会提供以下：
- 项目目录结构
- 核心代码文件
- GitHub 链接
- 提交记录片段
- 项目简单说明
2.我要应聘的岗位方向(如:java后端，前端，全栈等)

## 输出格式（严格遵守）

# 1. 项目名称
（简洁命名）

# 2. 项目背景
（2–4 行，简单说明：做什么、解决什么问题、面向谁）

# 3. 技术栈
按岗位方向突出展示，无关技术精简
- 语言：
- 框架：
- 数据库/缓存：
- 中间件/工具：
- 其他：

# 4. 核心功能
（每条控制在两行内，精炼、动词开头）
- 功能1
- 功能2
- 功能3
- 功能4

# 5. 个人负责部分
（根据代码、提交记录，还要结合我输入的岗位，找到对应的，符合技术要求的git提交记录，写出我实际开发内容）
- 负责模块1
- 负责模块2
- 负责模块3

# 6. 项目难点
(扫描代码库，结合我要求的岗位，分析出对应岗位的可以作为项目难点的技术难点)
(分析维度：
1. 架构复杂度 - 微服务、分布式、高并发处理
2. 性能优化 - 瓶颈、优化手段、效果
3. 工程化 - CI/CD、监控、自动化
4. 技术债务 - 重构、遗留系统改造
5. 创新点 - 自研框架、工具、解决方案

要求：
- 每个点用 STAR 法则描述
- 尽量找到量化的指标（QPS、延迟、代码量等）
- 指出具体文件/模块作为证据)
- 难点1
- 难点2
- 难点3
